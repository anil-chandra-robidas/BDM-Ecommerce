BDM-Ecommerce

Modern Luxury Next.js 14 E-Commerce Template with Built-in Visual Admin CMS & Page Builder.

Item Metadata

Created By:Anil Chandra Robidas (Envato Author)
Framework:Next.js 14.2 (App Router) + React 18.3 + TypeScript 5
Styling:Tailwind CSS 3.4 + Custom Tokens
Icons:Lucide React (400+ vector icons)
State Management:React Context API + LocalStorage Synchronization

✨ Standout Features

  • ⚡ Next.js 14 App Router: Static Site Generation (SSG) and Server-Side Rendering (SSR) for blazing performance.
  • 🛒 Persistent Shopping Cart & Slide-out Drawer: LocalStorage sync, line-item steppers, free shipping progress bar, and coupon vouchers (LUXE20).
  • 💖 Persistent Wishlist Portal: 1-click move-to-cart synchronization.
  • 💳 3-Step Express Checkout Wizard: Customer info, dynamic shipping calculator, and multi-method payments.
  • 🔍 Faceted Shop Filtering: Filter by categories, subcategories, price range sliders, minimum star ratings, and stock status.
  • 🎛️ Built-in Admin Studio & Visual CMS: Real-time live previews, order fulfillment workflow, catalog manager, and pages builder.

📋 System Requirements

Before installing and running this project locally, ensure you have the following installed on your machine:

  • Node.js: v18.17.0 or higher (v20+ recommended). Check with node -v.
  • NPM: v9.0.0 or higher (or yarn / pnpm / bun).
  • Modern Browser: Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge.

🚀 Installation & Setup

Follow these simple steps to get your storefront and admin studio running in under 2 minutes:

Step 1: Extract & Open Project

cd bdm-ecommerce

Step 2: Install NPM Dependencies

npm install

Step 3: Launch Local Development Server

npm run dev
💡 Success! Open http://localhost:3000 in your browser to view the storefront, or http://localhost:3000/admin to view the Admin Studio.

Step 4: Create an Optimized Production Build

npm run build
npm start

💾 State Management & Context Architecture

BDM-Ecommerce uses standard React Context API synchronized with browser localStorage for state persistence with zero hydration errors:

1. CartContext (context/CartContext.tsx)

  • items: CartItem[] — Active cart items.
  • addToCart(product, quantity, color, size) — Add item or increment existing.
  • removeFromCart(productId, color, size) — Delete item line.
  • updateQuantity(productId, quantity, color, size) — Change item quantity.
  • subtotal, discount, shipping, total — Computed financial sums.
  • isCartOpen, setIsCartOpen — Controls the slide-out cart drawer.

2. WishlistContext (context/WishlistContext.tsx)

  • items: Product[] — Favorited items array.
  • addToWishlist(product) / removeFromWishlist(id) — Toggle favorite status.
  • moveToCart(product) — Transfers item directly to shopping cart.

🎛️ Admin Studio & Visual CMS

The Admin Dashboard (/admin) allows instant zero-code customization with live real-time preview frames:

1. Header & Navigation Studio

  • Announcement Ribbon: Enable/disable, change ribbon text, and configure coupon vouchers (LUXE20).
  • Brand Logo & Taglines: Update store name and subtitle badge.
  • Header Action Icons: Toggle Search, Wishlist, Account, and Cart icons.
  • Navigation Manager: Add custom menu routes using the + Add Nav Item modal.

2. Footer & Guarantees Studio

  • Company Profile: Bio story, physical address, support phone, and support email.
  • Value Guarantees: Manage store pledges with the + Add Guarantee modal.
  • Quick Links & Service Links: Add links with dedicated modals.
  • Social Channels Hub: Configure Instagram, Twitter/X, Facebook, YouTube, and GitHub URLs.

3. Pages Visual Builder

  • Home Page Creator: Customize hero headline, narrative subtitle, CTA buttons, background photo, flash sale card, and customer testimonials with star ratings.
  • About Us Creator: Edit mission story, add core values, leadership team profiles, and timeline milestones.
  • Contact Us Creator: Configure SLA response time, global flagship showrooms (New York, London, Tokyo), and interactive FAQ questions.

🚢 Production Deployment (Vercel)

  1. Push your source code to GitHub / GitLab / Bitbucket.
  2. Log in to Vercel and click "Add New Project".
  3. Import your Git repository.
  4. Vercel will auto-detect Next.js:
    • Framework Preset: Next.js
    • Build Command: npm run build
    • Output Directory: .next
  5. Click Deploy. Your site will be live on a global CDN in under 1 minute!
